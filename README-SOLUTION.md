# Обоснование декомпозиции

`App.vue` оставлен контейнером страницы: он связывает загрузку данных, выбранное поле поиска, поисковый запрос и отображение соответствующего состояния. `UserSearch` отвечает только за ввод параметров поиска, `UserList` — за отображение коллекции пользователей, а `UserCard` — за представление отдельного пользователя. Такое разделение упрощает чтение компонентов и позволяет изменять поиск, структуру списка или внешний вид карточки независимо друг от друга.

Логика загрузки вынесена в composable `useUsers`, чтобы отделить работу с API и состояниями `loading/error` от разметки. `Loader` и `ErrorState` оформлены отдельными компонентами, поскольку эти состояния имеют собственное отображение и могут переиспользоваться. При этом фильтрация остаётся в `App.vue`, так как она связывает данные пользователей с параметрами конкретной страницы и пока недостаточно сложна для отдельного composable.

Также создан отдельный файл `constants.js` для хранения констант.
